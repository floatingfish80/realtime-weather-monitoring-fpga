# Real-time FPGA Weather Monitering System
Basys3 implementation using DHT11 Temperature and Humidity sensor
by Hanuman Mattupalli

## Description
This prject an FPGA-based integrated system combining a 12-hour digital clock with DHT11 environmental sensing, featuring dynamic display multiplexing, adaptive sensor polling, and context-aware controls. The design 
demonstrates efficient resource sharing with <15% overhead while maintaining high accuracy in both timekeeping (±1 sec/day) and sensor readings (±2°C, ±5% RH). The system provides a compact solution for
multifunctional edge devices, validated through hardware implementation and real-world testing.
